# Web Robot Patroli Keamanan: berkas Modul 4

Salin folder app/, components/, lib/, dan docs/ ke proyek Next.js Anda
(timpa berkas yang sama). Nama rute dan fungsi (daftarItem, cariItem,
/katalog/[id]) sengaja mengikuti modul; temanya ada pada isi data dan teks.

Terminal:
  npm install server-only
  npx tsc --noEmit && npm run lint && npm run build

Catatan:
- Sesuaikan impor dan gaya dengan berkas Modul 1-3 Anda (globals.css, Tailwind).
- app/uji/ hanya untuk pengujian; hapus setelah Bagian 5.
- Jangan ubah flag cacheComponents di next.config.ts.
- Uji impor lib/data.ts dari DaftarItem (Bagian 4 no. 5) dilakukan sendiri, lalu dicatat.
